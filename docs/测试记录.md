# 0.4.3-compat.2 测试记录

2026-11-04，本地 Chrome 无头浏览器，390×844 视口，合成消息与模拟酒馆/助手。24 项检查通过，详细结果保存在 `TEST-RESULTS.json`。

## 与旧测试的区别

旧测试允许 `visible.every(...)` 在视口内没有消息时通过，只看队列 ready 而不检查 pending，也没有覆盖助手的 runtime 强引用和 DOM 替换监听。旧 10 项测试不能证明真实助手下的前端启动并发或内存稳定。

新模型核对酒馆助手 4.12.0 / 40e4b72 的范围审计、缺 DOM 时仍审计其他楼层、目标 runtime 卸载和同 mesid 的 DOM 替换恢复。对已发布 compat.1 的复现用例确认：一次跳进巨大占位区后视口空白，并留有已移出 DOM 的 runtime 引用。
