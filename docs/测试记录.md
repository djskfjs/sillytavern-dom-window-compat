# 测试记录

## 0.4.3-compat.5 — 2026-11-07

通用浏览器兼容实现共完成 **86 项本地检查**：34 项助手配置/队列/存储/诊断单元测试、22 项 Chrome 通用回归、10 项 Chrome 滚动与设置回归、10 项 Chrome 异常和后台兼容检查、10 项桌面 WebKit 异常和后台兼容检查。检查使用合成聊天与模拟助手，不使用真实聊天或密钥。本地验证阶段保留了 `0.4.3-compat.4` 版本号，此次发布统一更新为 `0.4.3-compat.5`。

### 本次确认的行为

- 前台恢复超过实际 15 秒时，暂停窗口、保留当前 DOM 与助手备份，不自动刷新或批量恢复历史楼层。
- 后台停留超过实际 16 秒不消耗前台超时预算；前台继续同一个任务，不叠加第二个恢复调用，已有 iframe 继续复用。
- 挂载异常后暂停；用户主动关闭时仍可恢复原助手设置。生成期间点击刷新不导航，生成结束后可手动刷新。
- 浏览器禁止存储时能完成初始化，不创建无法保留归属的助手配置备份；剪贴板不可用时保留可选择的诊断文本。
- 诊断使用字段白名单，不包含聊天正文、角色名、网址或密钥；程序刷新标记在 pagehide 后仍保留。
- 有/无助手备份的后台卸载均完成：恢复测试默认的 20 层普通消息、清除所有窗口占位、移除扩展 API 与设置面板，不自动重载。
- 原有 120 轮历史往返、重叠 iframe 复用、异步回收和阅读位置检查继续通过。

检查明细见 [本地验证明细](本地预览测试.json)。两项可选的上游/旧版历史对照因未提供源码没有运行，不计入通过数量。Firefox 执行器未取得有效结果，不算通过。**iPhone/Via 真机尚未验证**，桌面 WebKit 结果不能证明真实手机的系统回收或自动重载已经完全解决。

## 0.4.3-compat.4 — 2026-11-05（历史记录）

2026-11-05：45 项本地检查通过，包括 11 项设置保存/恢复检查、24 项通用浏览器回归、10 项滚动与操作检查。使用桌面 Chrome 无头浏览器和合成聊天，不使用真实聊天或密钥。

### 当时新增行为

- 渲染深度 8、流式开启时，勾选一次窗口开关后自动保存、刷新一次并启用；关闭时还原 8/开启，刷新一次。
- 只改保存设置不改变模拟助手当前渲染副本，必须跨真实页面重载验证配置生效。
- 10→15→5 层点击保存后立即生效，页面加载次数不变；两次采样中的原阅读楼层位置偏移均为 0px，重叠 iframe 实例保留。
- 关闭状态保存 12 层不刷新，下次启用采用该设置。缺少 crypto.randomUUID 的环境也能初始化。
- 关闭过程中中断后，重载时从账号中本浏览器的备份恢复原深度。另一个浏览器不会恢复或清除该备份。
- 保存接口即使返回成功的 Promise，也必须收到 SETTINGS_UPDATED；未收到时回退且不刷新。恢复失败保留备份以便重试。
- 未适配版本、正在生成回复和无法识别的备份不会触发配置写入。之后被用户手动改过的字段在关闭时保留。

### 当时保留的回归

原有滚动专项继续通过：回收过程可见重叠行位移 0px、持续滚动仍会启动恢复、长源码不会撑出巨大空白、60 次小幅上滚不倒退。通用回归包括 120 轮往返、超高末楼、异步回收反向滑动、切换聊天和卸载恢复；模拟助手最多 11 个实例，无脱离 DOM 引用残留。

完整记录见 [TEST-RESULTS.json](TEST-RESULTS.json)，设置单元测试源码位于 tests/helper-setup.test.mjs。

这些测试不能证明 iPhone 的触摸惯性、黑屏和自动重载已经完全解决，仍需手机验证。
