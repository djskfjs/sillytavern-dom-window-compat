# 0.4.3-compat.3 测试记录

日期：2026-11-05。使用桌面 Chrome 无头浏览器、390×844 视口、合成聊天和模拟酒馆助手。24 项通用检查及 6 项滚动专项检查全部通过。

## 滚动专项

| 场景 | compat.2 对照 | compat.3 |
| --- | --- | --- |
| 屏幕下方末楼变高 | 仍写入一次相同 scrollTop | 无位置写入 |
| 每 25ms 继续滚动，持续 800ms | 恢复没有开始 | 约 245ms 开始恢复 |
| 助手回收每层延迟 60ms | 可见重叠楼层偏移 1908px | 逐帧采样最大偏移 0px |
| 页面自身开启自动滚动定位 | 与扩展同时工作 | 开启时禁用，关闭恢复原值 |
| 18000px 源码尚未恢复 | 隐藏后仍占约 18065px | 等待行约 907px，完成后释放临时高度 |
| 60 次每次 80px 的小幅上滚 | 对照也通过此项 | 前进约 5 层，无空白采样、无反向拉回 |

调度的 240ms 上限不代表真实前端必定在这个时间内完成；繁忙主线程、慢资源或正在进行的恢复调用仍可能延迟。

## 通用回归

保留旧／新楼层接口、快速跨占位区、异步回收期间反向滚动、12000px 末楼、历史中追加消息、重叠 iframe 复用、恢复中切换聊天、异常恢复、重复加载和卸载恢复等检查。120 轮跨历史往返中，模拟助手最多保留 11 个实例，脱离 DOM 的引用为 0。聊天数据快照未改变。

完整机器记录见 [TEST-RESULTS.json](TEST-RESULTS.json)。前端实例计数来自每楼一个 iframe 的合成模型，不能等同于真实聊天内存占用。
