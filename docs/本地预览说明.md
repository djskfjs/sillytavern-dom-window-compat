# 0.4.3-compat.5 发布说明 · 通用浏览器兼容

日期：2026-11-07。本次将已完成本地验证的通用浏览器兼容实现发布为 **0.4.3-compat.5**，继续使用原 GitHub 仓库。

## 这次改了什么

所有浏览器使用同一套处理逻辑，无需为不同用户分别安装补丁。保留用户自己设置的层数。

- 某层加载卡住、窗口恢复失败时显示“已暂停”，保留当前页面，不自动重载，也不突然把大量旧楼层重新加载出来。
- 切到后台时暂停新的前端恢复，后台停留时间不计入 15 秒前台超时。回来继续同一个任务，不叠加第二个调用，重新核对阅读位置。
- 保存助手配置后，如果已经开始生成或进入后台，等待用户点击“刷新页面”。上次关闭没有完成时，显示“恢复原助手设置”，不在后台偷偷刷新。
- 浏览器不允许保存数据时仍可使用当页设置；无法保存备份归属时不自动修改助手。助手启动慢时等待，版本或接口不兼容时说明原因并保留原聊天。
- 增加“复制诊断信息”，方便反馈浏览器版本、运行状态、楼层和前端数量。复制失败时可在文本框全选。没有聊天正文、角色名称、网址、密钥，也不会自动上传。
- 后台卸载会清除窗口占位、恢复普通消息显示，不再无限等待一个不能继续的队列。

## 安装与更新

推荐在酒馆「管理扩展程序」中更新 `https://github.com/djskfjs/sillytavern-dom-window-compat`，然后刷新页面，确认显示 `0.4.3-compat.5`。不需要为不同浏览器另装一份。

手动安装 ZIP 时：

1. 解压安装包，打开里面的 `sillytavern_dom_window` 文件夹。
2. 已安装此扩展时，备份原扩展文件，将解压文件覆盖到**原扩展目录里**，保留原来的目录名称。不要另装第二份一起启用。通过 GitHub 安装时，原目录可能叫 `sillytavern-dom-window-compat`。
3. 首次手动安装时，可把整个文件夹放入酒馆当前用户的第三方扩展目录。
4. 刷新酒馆，确认扩展版本为 `0.4.3-compat.5`，设置自己的阅读层数并开启。

安装包必须带有新增的 `runtime-support.js`，不能只替换 `index.js`。配置仍保存在酒馆/当前浏览器中，不需要删除聊天或角色卡。

出现“已暂停”时，当前阅读内容会保留，酒馆仍可正常添加消息；此时窗口暂不约束新增楼层。复制诊断后，在方便的时候点击“刷新页面”。正在生成回复时按钮会等待，不中断生成。

## 能力范围

这是一份统一维护的兼容实现；“通用”不表示所有浏览器、系统和角色卡都已实测，也不保证页面永不被系统回收。窗口减少已挂载楼层，完整聊天数据仍在浏览器中，每层也可能有多个前端、大图或动画。

酒馆助手的内部前端回收接口目前仍仅核对过 **4.12.0**。其他版本需要先核对接口再加入同一版本的适配，不使用未经确认的内部事件。未安装助手可使用纯文字窗口。

诊断中的 `programmaticReload` 表示扩展曾主动请求刷新，并记录配置/还原/手动恢复原因；没有这条标记不能单独证明 iOS 杀掉了页面进程。部分浏览器回收时不会保留上次诊断，此时原因仍是未知。
