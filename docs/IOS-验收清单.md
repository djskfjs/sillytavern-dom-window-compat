# iOS 真机验收清单

测试版：0.4.3-compat.1。桌面模拟结果不能替代本清单。

## 测试前

- 先结束当前生成，确认正常聊天已保存，并保留箱装备份。
- 只启用一个 DOM Window 版本。使用 GitHub 地址安装时，先在管理扩展中停用原版并刷新；手动替换时，旧版文件夹移出扩展目录备份。
- 记录：设备型号、iOS 版本、浏览器、酒馆版本、酒馆助手版本、主题、聊天楼层数量。
- 兼容版默认关闭。先在关闭时确认正常前端界面能显示。

## 开启后

1. 从默认预加载 5 层开始，确认最新回复与前端界面正常。
2. 慢慢上翻历史，确认等待提示后恢复前端，而不是永久停留在源码。
3. 较快上下滑动，再停止 5–10 秒；记录是否黑屏、是否恢复、是否存在重复或缺失展示。
4. 回到底部，确认最后一层正确；发送一条正常消息，确认新增楼层及保存状态正常。
5. 切换聊天再切回，确认没有其他聊天的前端残留。
6. 切换候选、编辑旧楼层，确认前端内容跟随正确候选。勿用唯一重要聊天做破坏性操作。
7. 关闭窗口模式，确认恢复原生展示和启用前的渲染数量。
8. 分别测试前台连续聊天、切换其他 App、锁屏后返回，区分前台黑屏和后台页面重载。

## 判定

- 任一前端长期只剩代码、反复闪烁、操作无响应或再次黑屏，先关闭兼容版并保存当前内容。
- 不反复恢复备份来修复纯展示故障；先确认真正缺失的是否只是页面展示。
- 反馈时提供版本、发生动作、是否在前台、恢复所需时间、控制台相关错误；不需要聊天正文或密钥。
- 即使本次通过，仍不能宣称“iOS 永不重载”；系统回收无法由此扩展完全阻止。
