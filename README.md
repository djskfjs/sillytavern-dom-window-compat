## 安装与使用

在酒馆的「扩展程序 → 安装扩展程序」填入：

```text
https://github.com/djskfjs/sillytavern-dom-window-compat
```

已有兼容版则在「管理扩展程序」更新，刷新页面确认版本为 `0.4.3-compat.6`。继续使用同一个仓库，不需要安装另一份扩展；原版和兼容版只启用一个。

1. 在 DOM Window 设置阅读窗口层数，例如 10，点击保存。
2. 勾选「启用窗口」。若助手设置需要适配，扩展会保存原值、自动配置并刷新一次，然后开启窗口。
3. 以后修改层数，点击保存立即应用，保留当前阅读位置，不需要刷新页面或重启服务器。
4. 关闭窗口时，扩展会还原它修改的助手设置；确实有设置需要还原时会自动刷新一次。原本就符合条件则开关都无需为配置刷新。

当前已适配 **酒馆助手 4.12.0**。检测到其他版本时会明确显示版本号，暂不使用未经核对的前端回收机制。未安装助手可以使用文字窗口。SillyTavern 需为 1.14 或以上。

## 自动适配的范围

扩展只按需调整助手的渲染深度和流式渲染：深度 0 让助手渲染窗口内已挂载的楼层，实际楼层数量由 DOM Window 控制；流式渲染临时关闭。原值随当前账号设置保存，并标记本浏览器，避免另一个浏览器误还原。关闭后，只恢复仍是适配值的字段，保留用户后来手动修改的其他值。

助手的保存设置和实际生效设置是不同副本，所以首次适配或还原需要刷新一次。只有确认设置保存成功才刷新，保存失败会回退并给出说明。保存后若已开始生成或进入后台，会显示“等待刷新”，由用户在方便时点击刷新。层数调整在当前页面直接完成。

## 行为与限制

- 不修改聊天数组、AI 上下文、消息 ID 或聊天保存内容。完整聊天数据仍留在浏览器中。
- 前端移出窗口后卸载，重新进入时会初始化，尚未保存的前端交互状态可能重置。
- 初次开启复用已显示的楼层；回收期间保留高度，避免滚动位置突然变化。持续滑动不会无限推迟前端恢复。
- 生成中显示“生成中，暂缓回收”，已有楼层继续显示，新回复由酒馆正常输出；移出当前已加载范围的历史楼层暂不补载。结束、停止或报错收尾后恢复窗口。已开始的一个助手调用无法强行取消，后续任务会等待。
- 一层可以包含多个 iframe，窗口层数不能当作内存上限。很短的楼层不足以填满屏幕时可适当增加层数。
- 恢复调用在前台累计超过 15 秒未响应，或窗口遇到异常时，会暂停新恢复任务并保留现有页面，不自动刷新、不自动还原大量楼层。暂停后新增消息由酒馆正常显示，窗口暂时不再约束新增楼层；用户可在方便时点击“刷新页面”。
- 切到后台、页面冻结或进入往返缓存时暂停队列与超时预算；返回前台继续剩余预算，复用原有前端。已开始的单个助手调用无法被强行中止，但不会叠加第二个调用。
- 配置保存后若页面进入后台或开始生成，改为显示“等待刷新”。关闭过程曾中断时显示“恢复原助手设置”，由用户点击恢复，不在后台自动刷新。
- 浏览器禁止保存数据时保留当页窗口设置；无法持久备份助手设置时不自动修改助手配置。助手 API 尚未启动时短暂等待，未知版本保留原聊天并显示原因。
- 若页面白屏后重新加载，等酒馆页面恢复，再点击“复制诊断信息”，无需额外重启服务器。浏览器保留会话存储时，信息会包含上次页面的部分状态和主动刷新标记。诊断只含浏览器版本、运行状态、楼层/前端数量和最多 24 条状态事件；不记录聊天正文、角色名称、网址或密钥，不上传数据。剪贴板不可用时可在文本框中全选复制。
- 这是兼容测试版。电脑测试不能证明 iPhone Chrome 的黑屏或自动重载已经完全解决，手机仍需按 [验收清单](docs/IOS-验收清单.md) 验证。

## 开发与打包

`npm test` 运行设置适配、队列、存储与诊断单元测试，以及通用浏览器、滚动、异常/后台兼容和生成期间回收测试。浏览器测试使用合成聊天，不使用真实聊天或密钥。环境变量：`DOM_WINDOW_BROWSER` 指定浏览器可执行文件；`DOM_WINDOW_BASELINE` 指向上游源码；`DOM_WINDOW_PREVIOUS` 指向 compat.1 源码；`DOM_WINDOW_TEST_OUTPUT` 指定记录目录；`DOM_WINDOW_TEST_SOURCE` 可用于滚动及生成测试对比其他版本。安全与生成测试可用 `DOM_WINDOW_ENGINE=webkit` 选择已安装的桌面 WebKit。

ZIP 安装时将 `sillytavern_dom_window` 放入实际第三方扩展目录；更新时覆盖原安装目录，勿同时启用两个 DOM Window。运行文件必须包含 `index.js`、`render-queue.js`、`moving-window.js`、`helper-lifecycle.js`、`helper-setup.js`、`runtime-support.js`、`settings.html`、`style.css` 和 `manifest.json`。

详见 [更新日志](CHANGELOG.md)、[测试记录](docs/测试记录.md) 和 [助手回收说明](docs/兼容回收说明.md)。

## 回退

发布前 GitHub 默认分支的版本为 `0.4.3-compat.4`，对应提交 [`0f9e4eb`](https://github.com/djskfjs/sillytavern-dom-window-compat/tree/0f9e4eb44a61228d7bf09eb11457aae3bb1d246c)。需要统一回退时，在主分支新增恢复该版本代码的提交，保留公开历史；用户继续从同一个仓库更新。临时手动回退也可使用该提交的文件覆盖原扩展目录后刷新。

回退扩展代码不需要删除或迁移角色、聊天与备份，也不会撤销用户后来自行修改的设置。
